# SonaTasks Bài 02
Ứng dụng Flutter thực hành layout màn hình Home; package của repository là `app_01`.
Có AppBar, thống kê 5 công việc, danh sách mẫu và FloatingActionButton.
Dùng Row, Column, Container, Padding, Expanded, Stack và ListView.
Mở rộng: thống kê thích ứng màn hình ngang và trang giới thiệu ứng dụng.
Cách chạy: `flutter pub get` rồi `flutter run -d chrome`; Android dùng `flutter run -d <device-id>`.
Kiểm tra: `flutter analyze`, `flutter test`, `flutter build web`; SDK đã kiểm tra: Flutter 3.47.4, Dart 3.13.3.
Ảnh giao diện ở `screenshots`; hướng dẫn kỹ thuật ở [HUONG_DAN_BAI_02.md](HUONG_DAN_BAI_02.md).
