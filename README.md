# SonaTasks Bài 03 kế thừa Bài 02
Khung chung: AppBar có chuông và tài khoản; menu Home, Task, About.
Home: logo trường và lời chào; About: môn học và phiên bản.
Task: form tên, mô tả, kiểm tra tên rỗng bằng SnackBar; lưu List bằng setState.
Checkbox đổi trạng thái; form xóa sau lưu; DropdownButton chọn ưu tiên.
Mở rộng: badge số việc chưa xong, Dialog tài khoản và Switch lọc.
Chạy: flutter pub get, flutter devices rồi flutter run -d <device-id>.
Kiểm tra: flutter analyze và flutter test; chạy Android theo hướng dẫn Word.
Ảnh thực tế trên Android được lưu trong screenshots.
Giới hạn: dữ liệu RAM, đổi tab giữ dữ liệu; khởi động lại trở về 5 mẫu Bài 02.
